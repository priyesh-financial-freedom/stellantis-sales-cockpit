This is a [Next.js](https://nextjs.org) project for the Stellantis India Sales Cockpit.

## Current Modules

- Sales Cockpit — daily sales management view with Monthly, Quarterly, Half-Yearly, Annual and Custom Period analysis.
- Jeep Model Wise — model-level sales analysis.
- Citroën Model Wise — model-level sales analysis.
- Data Entry — manual entry plus CSV import/export for daily sales and monthly model data.

## Data

The application uses Supabase for the Sales Cockpit daily and model-monthly datasets.

## Development

Run from the repository root:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## Deployment

Production deployments are triggered from the `main` branch through Vercel.
